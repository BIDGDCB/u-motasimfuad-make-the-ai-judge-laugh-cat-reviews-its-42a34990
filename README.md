# Make the AI Judge Laugh: Cat Reviews Its Human

make.fun entry. `main.ts` (Node 22, standard library only) writes one
funny single-line one-star review from a house cat about its human to
`/output/entry.txt`, validating the 1–200 character gate first.

Entry text:

> One star. The food arrives late, the sunbeam moved without notice, and when I sat on the keyboard to file a complaint he called it sabotage. I pay rent in hair. Avoid.
